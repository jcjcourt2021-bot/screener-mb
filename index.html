💡 How RUN works

Screener.in blocks direct browser fetches, so when you tap RUN the app routes each screener URL through free public CORS proxies (trying a couple in case one is down) and parses the returned table — no login, no popups.

  1. Screens must be public screener.in screens (proxies can't send your login cookie)
  2. Tap RUN — each screen is fetched via proxy in turn
  3. If a proxy is down or rate-limited it's skipped and the next one is tried
  4. Results appear automatically once all screens are fetched
